# 架构与数据约束

## 运行边界

Python 3.14 + Django 5.2 LTS + PostgreSQL 18。HTML由服务端渲染，HTMX局部更新任务状态；问答采用SSE，图表用原生Canvas并提供数据表。网页、调度器、采集、维护、AI各运行独立进程，共用模块化单体代码。数据库不暴露公网。

`core`负责任务、认证与容量，`news`负责文章版本及检索，`briefs`保存简报快照，`events`保存人工确认的节点，`ai`封装供应商。没有跨模块复制的第二套新闻状态JSON。

## 新闻与版本

规范化URL的SHA-256全局唯一，源内GUID另作身份映射。入库在短事务中采用URL事务锁和文章行锁，网络请求不持有这些锁。不同来源的独立报道保留独立文章，仅通过进展组关联。完全相同的内容指纹不新增版本；历史导入不能覆盖较新的内容版本。

保存RSS提供的文本；不采集文章网页正文。外部HTML剥离为文本，页面自动转义。抓取检查公网地址、标准端口、重定向次数、解压后响应体大小和超时。来源设置仅管理员可访问。

中文使用jieba词项及双字词，英文用字母/数字词项，查询采用相同处理；标题高权重、摘要低权重。为控制30GB磁盘占用，长正文及每个历史版本不单独建全文索引。文章列表按首次发现时间与ID做签名游标分页。普通文章核心表不分区，采集运行明细按月分区；默认分区接住意外月份，每小时维护当前及未来两个月分区。

## 任务与简报

任务通过唯一键入队、`SELECT FOR UPDATE SKIP LOCKED`领取，90秒租约、20秒续期。过期任务最多重试4次。执行语义为至少一次，数据入库、定时简报等业务通过唯一约束幂等。外部模型请求在网络故障后可能产生重复计费，不能承诺外部调用恰好一次。

采集全局最多6个运行任务，同域租约单并发；当前2GB服务器只启动1个采集Worker。AI默认全局并发1，可调至4；2GB服务器不建议提高。普通源10分钟、加速源2分钟；自动简报08:00、12:30、20:00。断线恢复时只补一份覆盖实际时段的简报，不追补RSS已经丢失的历史内容。

简报选稿按更新时间、分类权重、分类配额、来源上限和进展组去重。正文与标题保存快照，引用具体版本。定时生成不等待AI，后续中文生成不回写旧简报。每10分钟优先预处理最多40篇近期候选，未配置密钥时跳过。

## 事件与AI

手动建事件，关键词检索历史/新增报道形成候选。AI推荐关联并生成草稿，人确认后成为正式时间线。确认节点至少引用一篇存在的报道版本；合并、拆分和编辑保留引用，概况由最近5个已确认节点生成，不自动改写人工节点。首次回溯每关键词最多2000篇候选，避免模糊关键词一次扫描全库；可缩小时间段或关键词继续查询。

四个业务能力为 `enrich_article`、`suggest_event_links`、`draft_event_update`、`answer_archive`。供应商协议是DeepSeek Responses，默认`deepseek-flash`。不发送不支持的云会话、后台处理、内置检索参数。本地保存问答历史，提供只读搜索、版本读取和事件时间线函数工具；最多4轮工具交互、20篇证据、60000字符请求输入。输出使用JSON Schema并由Pydantic验证。流式文字仅为预览；完成且引用有效后保存正式答案。

默认每天20万输入/输出token。请求前保守预留，成功按usage结算，缺失usage按预留估算；配额不足的任务推迟到次日。缓存包含输入、模型及提示词版本。异常退出时可能留下当日保守预留，次日按新日期重新计数；宁可少花额度，不越过预算。

## 生命周期

普通文章180天，非引用旧版本30天，详细采集记录14天；小时统计长期保存。简报、收藏、已确认事件引用版本永久保护。最近72小时和待运行/运行中任务关联文章暂时保护。未确认AI草稿7天过期，问答90天。

数据库16GB目标预算；剩余8GB触发提前批量淘汰，剩余6GB暂停采集和AI。每轮最多10批、每批200篇，防止长事务。删除后保留30天身份墓碑。PostgreSQL常规清理复用内部空间，不保证操作系统空闲量立即上涨；不会自动执行VACUUM FULL。数据库保护内容不断增长时仍需要扩容或人工解除保护。

统计按真实请求时间聚合；304算成功，未执行与失败分开，导入数量单独记录。容量、平均占用和保留跨度是估算，界面明确标注。

## 私有接口

所有业务页面和`/api/v1/`使用Django会话认证，写操作要求CSRF；登录每来源IP每15分钟最多10次。`/health/`只返回可用状态。

- GET `/api/v1/news/`：q、feed、category、start、end、cursor，返回items和next_cursor。
- GET `/api/v1/briefs/`、`/api/v1/events/`：最近条目。
- GET `/api/v1/stats/`：days或start/end、bucket。
- POST `/api/v1/actions/`：与页面操作共用服务；action包括collect、brief、enrich、seed、confirm、edit_node、merge_node、split_node、group、ungroup、favourite、capacity。耗时操作返回202及job。
- POST `/api/v1/answer/`：question及可选conversation，返回job与conversation。
- GET `/api/v1/jobs/UUID/`、`.../stream/`：任务状态或SSE。

供应商密钥只读服务器私有环境配置，永不返回浏览器。引用以具体报道版本定位，已淘汰的非保护问答证据不能再完整回读。

## 第三方

前端内置HTMX 2.0.8（0BSD许可证，https://github.com/bigskysoftware/htmx）；Python依赖及版本记录在uv.lock中。浏览器不从外部CDN加载脚本。
